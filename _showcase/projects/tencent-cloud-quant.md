    <h2 data-en="Tencent Cloud Quant Infrastructure Grant: Low-Latency APAC Trading Backbone" data-zh="腾讯云量化基础设施资助：低延迟亚太交易骨干网">
        Tencent Cloud Quant Infrastructure Grant: Low-Latency APAC Trading Backbone
    </h2>
    <hr />

    <div class="row">
        <div class="col-md-8">
            <p data-en="A cloud infrastructure grant from Tencent Cloud International, supporting latency-sensitive quantitative trading and agent workloads on low-latency APAC nodes interconnected over Tencent's private backbone." data-zh="来自腾讯云国际的云基础设施资助，用于在低延迟亚太节点与腾讯私有骨干网互联之上，支撑对延迟敏感的量化交易与 Agent 工作负载。">
                A cloud infrastructure grant from Tencent Cloud International, supporting latency-sensitive quantitative trading and agent workloads on low-latency APAC nodes interconnected over Tencent's private backbone.
            </p>

            <h4 data-en="What the infrastructure provides" data-zh="基础设施能力">What the infrastructure provides</h4>
            <ul>
                <li data-en="<strong>Low-latency APAC nodes</strong>: high-availability regions in Hong Kong and Singapore, physically close to major exchanges" data-zh="<strong>低延迟亚太节点</strong>：香港与新加坡的高可用区域，物理上贴近主要交易所">
                    <strong>Low-latency APAC nodes</strong>: high-availability regions in Hong Kong and Singapore, physically close to major exchanges
                </li>
                <li data-en="<strong>CCN private-backbone interconnect</strong>: Cloud Connect Network links regions over a private backbone rather than the public internet, keeping cross-region latency stable and free of public-BGP jitter" data-zh="<strong>CCN 私有骨干网互联</strong>：Cloud Connect Network 通过私有骨干网而非公网连接各区域，使跨区延迟稳定、不受公网 BGP 抖动影响">
                    <strong>CCN private-backbone interconnect</strong>: Cloud Connect Network links regions over a private backbone rather than the public internet, keeping cross-region latency stable and free of public-BGP jitter
                </li>
                <li data-en="<strong>Financial-grade compliance</strong>: SOC 2 Type II, ISO 27001 and PCI DSS, plus regional certifications (Hong Kong ICAR, Singapore MTCS)" data-zh="<strong>金融级合规</strong>：SOC 2 Type II、ISO 27001 与 PCI DSS，以及区域认证（香港 ICAR、新加坡 MTCS）">
                    <strong>Financial-grade compliance</strong>: SOC 2 Type II, ISO 27001 and PCI DSS, plus regional certifications (Hong Kong ICAR, Singapore MTCS)
                </li>
            </ul>

            <h4 data-en="How I plan to use it" data-zh="使用方向">How I plan to use it</h4>
            <ul>
                <li data-en="Latency and jitter benchmarking of a trading loop across APAC regions, measured against a public-internet baseline" data-zh="在亚太多区域上对交易闭环做延迟与抖动基准测试，并与公网基线对比">
                    Latency and jitter benchmarking of a trading loop across APAC regions, measured against a public-internet baseline
                </li>
                <li data-en="Backtesting and agent-rollout runs that extend the <a href=&quot;/showcase.html#projects&quot;>Quant Trading Agent</a> built at AQUMON — LangChain orchestration over Futu OpenAPI real-time data and automated execution" data-zh="在 <a href=&quot;/showcase.html#projects&quot;>Quant Trading Agent</a>（AQUMON 期间开发，基于 LangChain 编排、对接 Futu OpenAPI 实时行情与自动下单）之上开展回测与 Agent rollout">
                    Backtesting and agent-rollout runs that extend the <a href="/showcase.html#projects">Quant Trading Agent</a> built at AQUMON — LangChain orchestration over Futu OpenAPI real-time data and automated execution
                </li>
                <li data-en="Serving experiments for agentic post-training workloads where decision latency, not throughput, is the binding constraint" data-zh="面向 Agentic 后训练工作负载的推理部署实验——瓶颈在决策延迟而非吞吐">
                    Serving experiments for agentic post-training workloads where decision latency, not throughput, is the binding constraint
                </li>
            </ul>
