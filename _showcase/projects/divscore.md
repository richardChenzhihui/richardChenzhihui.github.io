<h2 data-en="DivScore: Zero-Shot LLM Detection in Specialized Domains (EMNLP 2025)" data-zh="DivScore: 专业领域中的零样本大语言模型检测（EMNLP 2025）">DivScore: Zero-Shot LLM Detection in Specialized Domains (EMNLP 2025)</h2>

<p data-en="A zero-shot detection framework for identifying LLM-generated text in specialized domains like medicine and law, using normalized entropy-based scoring and domain knowledge distillation." data-zh="一个零样本检测框架，用于识别医学和法律等专业领域中的大语言模型生成文本，使用归一化熵评分和领域知识蒸馏。">
    A zero-shot detection framework for identifying LLM-generated text in specialized domains like medicine and law, using normalized entropy-based scoring and domain knowledge distillation.
</p>

<h4 data-en="Key Innovations" data-zh="核心创新">Key Innovations</h4>
<ul>
    <li data-en="<strong>Zero-shot detection</strong>: No training data required for new domains" data-zh="<strong>零样本检测</strong>：新领域无需训练数据">
        <strong>Zero-shot detection</strong>: No training data required for new domains
    </li>
    <li data-en="<strong>Normalized entropy scoring</strong>: Robust metric for specialized text" data-zh="<strong>归一化熵评分</strong>：专业文本的稳健指标">
        <strong>Normalized entropy scoring</strong>: Robust metric for specialized text
    </li>
    <li data-en="<strong>Domain knowledge distillation</strong>: Leverages domain-specific patterns" data-zh="<strong>领域知识蒸馏</strong>：利用领域特定模式">
        <strong>Domain knowledge distillation</strong>: Leverages domain-specific patterns
    </li>
    <li data-en="<strong>Cross-domain robustness</strong>: Tested on medical, legal, and financial texts" data-zh="<strong>跨领域鲁棒性</strong>：在医学、法律和金融文本上测试">
        <strong>Cross-domain robustness</strong>: Tested on medical, legal, and financial texts
    </li>
</ul>
